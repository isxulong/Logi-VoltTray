# 发布说明

## v0.3.6

红蓝对抗审查收敛版本：修复 3 个 P2，同批带走若干 P3。

> ⚠️ **给 v0.3.3 / v0.3.4 用户的提醒**：这两个版本的自定义颜色曾被字节序 bug 写错（D-52 已于 v0.3.5 修复转换链路）。受损色值与正确色值无法自动区分，因此**不做自动迁移**——**在 v0.3.3 / v0.3.4 选过自定义颜色的用户，请在 v0.3.6 重新选择一次**（设置窗口 → 字体颜色 / 背景 → 选色）。

### P2 修复

- **F3 自绘按钮焦点态**：焦点态现在画 2px 强调色内描边（浅主题 #0078D4 / 深主题 #60CDFF），键盘 Tab 走查可见（规范裁决 6）。
- **F2 阈值非法校验反馈**：阈值框输入非法（非 1–99 整数 / 非严格递增）时，输入框外缘出现 1px 错误色描边，分档卡内右侧同步显示红色提示；反馈不再占用底部状态行，不会被对比度提示覆写。非法值不会写入配置。
- **F1 存量受损颜色值处置策略**：明确不做自动迁移（理由与依据见 docs/decisions.md D-61），用户提示见上方提醒。

### P3 同批修复

- 自动 → 自定义 → 自动往返切换不再丢失已选自定义颜色。
- 滑块行补充最小—最大范围标注（如 40–160）。
- 分档说明示例按当前档数 / 阈值实时拼写。
- 配置热重载时同一组迁移告警只提示一次，不再重复刷屏。
- 决策记录勘误：D-53（ICO 实际 7 个尺寸全部 PNG 编码）、D-56（「行为保持不变」表述失实，默认用户所见会从单色变为分档色，种子阈值保留旧变色点）。
